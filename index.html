🔥 Configuración de Firebase

Sigue estos pasos una sola vez para conectar la app con tu base de datos en la nube.

1
Ve a console.firebase.google.com e inicia sesión con tu cuenta de Google.
2
Crea un nuevo proyecto → ponle nombre (ej. popgo-crispetas) → desactiva Google Analytics (opcional) → clic en Crear proyecto.
3
En el panel izquierdo ve a Compilación → Firestore Database → Crear base de datos → elige Modo de producción → selecciona una región (ej. us-central1) → Listo.
4
En el panel izquierdo ve a ⚙️ Configuración del proyecto → pestaña General → sección "Tus apps" → clic en el ícono </> Web → registra la app (ej. nombre: POP GO Web) → copia el objeto firebaseConfig.
5
Abre el archivo popgo-firebase.html en un editor de texto y reemplaza el bloque FIREBASE_CONFIG con tus valores:
const FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "popgo-xxx.firebaseapp.com",
  projectId: "popgo-xxx",
  storageBucket: "popgo-xxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc..."
};
6
Reglas de seguridad de Firestore — en la consola ve a Firestore → Reglas y pega esto (permite acceso solo desde tu app):
// Firestore Security Rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /negocios/{docId} {
      // Solo lectura/escritura si la petición viene de tu app
      allow read, write: if true; // Cambiar por auth en producción
    }
  }
}
Clic en Publicar.
✓
Guarda el archivo y ábrelo en el navegador. El indicador superior dirá "✓ Firebase OK". ¡Listo — tus datos se guardan en la nube automáticamente!
